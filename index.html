Welcome

Hello and welcome to the Student Profile & Course Portal. This website is designed to give you an overview of a student's academic journey, including personal details, enrolled courses, grades, and contact information.

Introduction

This portal is a simple HTML-only project built using only semantic HTML5 tags. It demonstrates how to structure a multi-page website using proper elements like header, nav, main, section, article, aside, and footer.

Feel free to explore each page from the navigation above.

Use the navigation links to visit the Profile, view the list of Courses, submit Feedback, check your Grades, or get in touch through the Contact page.
